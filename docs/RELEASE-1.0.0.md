# Release 1.0.0

## Браузерный редактор

- Кликабельные ошибки с переходом к точному полю.
- Краткие лорные карточки рас, профессий, происхождений, верований и языков.
- Помощник концепции из шести вопросов.
- Полный итоговый лист с печатью/PDF и экспортом HTML/TXT.
- Загрузка внешних пакетов `.flrules`.
- Формат `.flchar` v5 со стабильным `characterId`.

## Foundry-модуль

- Настройки пакета кампании на уровне мира.
- Экспорт `.flrules` из актуальных компендиумов.
- Предварительная сверка правил и источников всех Items.
- Предупреждения об изменённых или отсутствующих источниках.
- Ручной выбор создания нового Actor или обновления ранее импортированного.
- Сохранение вручную добавленного снаряжения при обновлении.
- Общая кодовая база Foundry VTT 13/14.

## Проверка

Пройдены тесты движка, ZIP-контейнера, браузерного интерфейса и двухверсионной совместимости.
