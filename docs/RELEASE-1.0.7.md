# Версия 1.0.7

## Отмена покупок Base XP на месте

- В каждой строке навыка появилась кнопка отмены последнего повышения этого навыка за Base XP.
- Расовый талант, первый Professional Path и выбранные General Talents позволяют вернуть последнее XP-повышение там же, где доступна покупка следующего ранга.
- В трёхколоночном каталоге General Talents у выбранного таланта показываются отдельные кнопки `−` и `+`.
- Купленное за Base XP заклинание удаляется прямо из каталога заклинаний или списка выбранных заклинаний.
- Для купленной Reputation добавлена отдельная кнопка возврата.
- Каждая запись журнала Base XP получила собственную кнопку «Отменить». Глобальная отмена последней покупки сохранена.

## Зависимые операции

При удалении покупки редактор заново воспроизводит журнал в исходном порядке. Совместимые последующие покупки сохраняются. Операции, потерявшие предварительные условия, удаляются с отдельным уведомлением.

## Проверка

Добавлен браузерный тест покупки и отмены навыка в одной строке, а также проверка наличия индивидуальной отмены у записей журнала и заклинаний. Все тесты движка, ZIP-контейнера, браузерного интерфейса и совместимости Foundry VTT 13/14 проходят.
