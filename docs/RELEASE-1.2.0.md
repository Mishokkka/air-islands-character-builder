# 1.2.0

- Добавлена сборка и публикация через GitHub Pages.
- Правила автоматически загружаются по `rules/manifest.json`.
- Проверяются версия формата, минимальная версия билдера, размер, SHA-256 и внутренний `packageHash`.
- Текущий и предыдущий пакеты правил сохраняются в IndexedDB.
- Добавлены ручная проверка обновлений, откат и аварийная загрузка `.flrules`.
- Service Worker кэширует оболочку приложения для работы без сети после первого открытия.
- `.flchar` packageVersion 3 включает `rules.json`.
- Импортёр использует проверенные правила из `.flchar`, если они отличаются от встроенной версии.
- Добавлен готовый GitHub Actions workflow и инструкция публикации.
