# Версия 1.0.8

## Окно импорта

- Высота окна предварительной проверки теперь рассчитывается относительно текущего размера экрана.
- Сводка персонажа прокручивается в отдельной внутренней области.
- Выбор режима импорта остаётся закреплён под сводкой, а стандартные кнопки DialogV2 больше не оказываются за пределами окна.
- Добавлены отдельные стили для низких экранов.

## Импорт в существующего Actor

Добавлен новый режим «Очистить и заменить выбранного существующего персонажа».

- В списке показываются все Actor типа `character` текущего мира.
- Перед заменой выводится отдельное подтверждение с именем выбранного Actor.
- У выбранного Actor удаляются все Items и Active Effects.
- Старые `system`, `flags`, изображение и данные прототипа токена заменяются импортированными данными.
- Папка Actor, его идентификатор и права доступа сохраняются.
- Прежний режим обновления по `characterId` остаётся отдельным и по-прежнему сохраняет вручную добавленные предметы.

## Проверка

Обновлены статические проверки совместимости Foundry VTT 13/14. Добавлены проверки нового режима полной замены, удаления Embedded Documents и прокручиваемой компоновки окна импорта.
