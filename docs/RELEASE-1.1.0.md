# Версия 1.1.0

Обновление встроенных каталогов и новая профессия.

## Каталоги

- Таланты заменены актуальным экспортом компендиума `world.talents`.
- Заклинания заменены актуальным экспортом компендиума `world.spellscomplete`.
- Обновлённые HTML-описания и новые контрольные хеши попадают в `.flrules`, тултипы и резервные snapshots.
- Старые стабильные `catalogId` сохранены для совпадающих талантов и заклинаний, несмотря на смену UUID и ID в компендиумах.
- Исправление названия `Physican` → `Physician` также сохраняет совместимость со старыми персонажами.

## Monster Hunter

Добавлена профессия `Monster Hunter` (`monster-hunter`).

- Фокус: WIT.
- Профессиональные навыки: Scouting, Lore, Survival, Crafting, Healing.
- Professional Paths: Path of the Dossier, Path of the Arsenal, Path of the Slayer.

Monster Hunter включён по умолчанию в новые пакеты кампании. В существующем мире он автоматически добавляется в список доступных профессий только тогда, когда до обновления были включены все прежние профессии.
