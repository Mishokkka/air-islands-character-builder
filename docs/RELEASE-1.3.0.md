# 1.3.0

## Новая BIO-интеграция

- `.flchar` обновлён до формата v8.
- Слухи теперь содержат отдельное имя персонажа или источника.
- Импортёр формирует полный `biographyProfile` для Quick Access 1.7.0.
- Переносятся личные сведения, Pride, Dark Secret, предыстория, семья, мотивация, связь с группой, публичная заметка, ответы на вопросы, языки и слухи.
- Для языков сохраняются название, уровень, родной статус и вычисленная стоимость изучения.
- Карта пилигрима получает имя, расу, подрасу, страну выдачи, дату рождения, портрет и физическое описание.
- Нативные Face, Body и Clothing больше не используются импортёром как активные поля.

## Совместимость

- Импорт через Quick Access API используется при наличии Quick Access 1.7.0.
- При отсутствии или старой версии Quick Access данные сохраняются напрямую в совместимый actor flag и появятся после обновления модуля.
- Старые `.flchar` v2–v7 продолжают открываться и мигрируют в v8.
