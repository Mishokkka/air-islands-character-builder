# Версия 1.0.5

- Дата кампании обновлена до 1 Хладохода 882 П.П.
- Удалены служебные плашки временной даты и версии пакета из браузерного редактора.
- Поля года, трилуния и дня рождения размещены в одной строке и делят её поровну.
- Значок справки Base XP расположен непосредственно после заголовка поля.
- Бесплатные стартовые заклинания ограничены пятью на Rank 1 и четырьмя на Rank 2.
- За Base XP можно докупить пятое заклинание Rank 2; общий лимит остаётся пять заклинаний каждого ранга.
