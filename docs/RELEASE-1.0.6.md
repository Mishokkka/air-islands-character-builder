# Версия 1.0.6

Foundry-модуль теперь позволяет ГМу принудительно импортировать персонажа, даже если файл не прошёл проверку правил.

Изменения:

- ошибки больше не блокируют кнопку импорта;
- перед принудительным импортом показывается отдельное подтверждение с предупреждением о последствиях;
- исходные характеристики переносятся в Actor даже при нарушении лимитов;
- навыки, таланты и заклинания переносятся в той части, которую движок смог корректно воспроизвести;
- неизвестные и невоспроизводимые операции пропускаются;
- полный список ошибок и предупреждений сохраняется в `flags.air-islands-character-importer.audit`;
- принудительный импорт работает и для создания нового Actor, и для ручного обновления ранее импортированного персонажа;
- обычный импорт валидного персонажа работает без дополнительного подтверждения.
