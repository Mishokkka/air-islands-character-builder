# Этап 5: каталоги талантов и заклинаний

Версия проекта: 0.5.0.

## Изменения правил

- При создании персонажа выбирается только один Professional Path.
- Base XP может повышать только этот первый Path.
- Покупка другого Path через изменённый `.flchar` блокируется движком и импортёром.
- Условные фокусы профессии, включая AGI у Fighter с Path of the Bullet, учитываются только от первого Path.

## Браузерный редактор

- Исправлена читаемость кнопок в тёмной шапке.
- Все General Talents показаны в отдельной таблице из трёх колонок.
- В каталоге видны только название и кнопка `+`; выбранные таланты подсвечиваются.
- Источник покупки выбирается в компактном меню после нажатия `+`.
- Все заклинания доступных школ показаны по рангам и школам.
- Каждый ранг имеет счётчик `выбрано / 5` и отдельный счётчик обязательных стартовых заклинаний.
- Стартовые заклинания можно добавлять и удалять прямо из каталога.
- Купленные за Base XP заклинания помечаются и отменяются через последовательный XP-журнал.

## Тултипы

Наведение или клавиатурный фокус на названии таланта или заклинания открывает карточку с:

- полным описанием;
- всеми рангами таланта;
- школой и рангом заклинания;
- дистанцией, длительностью и ингредиентом, если они указаны.

HTML описаний очищается перед выводом. Интерактивные Foundry-ссылки преобразуются в обычный текст.
