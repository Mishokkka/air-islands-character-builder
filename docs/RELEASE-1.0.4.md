# Версия 1.0.4

## Base XP

- Поле текущего Base XP перенесено на первый этап создания.
- На развитие персонажа доступно 20% от указанного текущего Base XP с округлением вверх.
- В интерфейсе, итоговой проверке и импортёре отдельно показываются текущий опыт, доступный бюджет, расход и остаток.
- Формат `.flchar` обновлён до v6. Старые v5-файлы мигрируют без потери прежнего доступного бюджета.

## Языки

- Очки языков рассчитываются только из стартовых WITS и Lore.
- Повышение Lore за Base XP больше не увеличивает языковой бюджет.

## Биография

- Полная анкета импортируется в поле Bio листа персонажа.
- Для поля Note добавлено отдельное публичное описание персонажа: то, что наверняка знают товарищи и знакомые.
- Заголовки физических особенностей и вопросов выводятся только жирным курсивом, без цветовых и иных встроенных стилей.

## Интерфейс и последовательность создания

- Окно настроек кампании ограничивается высотой экрана и получило собственную вертикальную прокрутку.
- Изменение характеристик и стартовых навыков больше не обнуляет совместимые таланты, заклинания и покупки за Base XP.
- При фундаментальных изменениях редактор сохраняет совместимые операции и удаляет только несовместимые.
- На вкладке талантов можно сразу изучить требуемое заклинание своей школы перед повышением магического Path, не переходя на вкладку заклинаний.
