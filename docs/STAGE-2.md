# Этап 2: проверяемые журналы создания и Base XP

## Каноническая модель `.flchar` v2

Файл больше не хранит вручную заданные итоговые ранги как источник истины.

Он содержит:

- стартовые характеристики и навыки;
- бесплатный первый Professional Path;
- журнал расходования возрастных очков талантов;
- список бесплатных стартовых заклинаний;
- последовательный журнал покупок за Base XP;
- языки, биографию и пояснения Reputation.

Итоговое состояние воспроизводится одинаковым кодом в автономном приложении и в Foundry.

## Возрастные очки талантов

Допустимы только следующие операции:

- получение или повышение General Talent, 1 очко за каждый ранг;
- повышение бесплатного первого немагического Path, 1 очко за ранг;
- повышение бесплатного первого магического Path, 2 очка за ранг.

Дополнительный Professional Path нельзя получить за возрастные очки. Все очки возраста должны быть потрачены.

## Base XP

Каждая операция журнала повышает ранг ровно на один или покупает один новый элемент:

- навык;
- талант или Professional Path;
- заклинание;
- 1 пункт Reputation.

Стоимость вычисляется на момент операции. Для таланта сначала применяется прибавка за число отдельных талантов, затем множители магического или расового таланта.

## Магия

Ранг первого магического Path после возрастных покупок определяет стартовый набор:

- ровно пять заклинаний Rank 1;
- ещё пять Rank 2 при Path Rank 2;
- и так далее.

Для каждого ранга действует общий лимит пять заклинаний по всем школам.

Заклинание за XP можно изучить не более чем на один ранг выше соответствующего Path. Перед повышением магического Path до нового ранга в журнале уже должно находиться хотя бы одно заклинание этого ранга из его собственной школы.

## Защита импорта

Foundry не доверяет записанным пользователем итогам. Импортёр заново:

1. определяет возрастную категорию;
2. проверяет стартовые бюджеты;
3. проигрывает возрастной журнал;
4. проверяет стартовые заклинания;
5. последовательно проигрывает Base XP;
6. рассчитывает языки и Reputation;
7. только после этого создаёт Actor.
