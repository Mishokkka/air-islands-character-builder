# Версия 1.0.10

## Исправлено

- Полная замена существующего Actor больше не удаляет обязательные поля `prototypeToken`.
- Для Foundry VTT 13 при замене явно восстанавливаются обязательные `texture.offsetX`, `texture.offsetY` и `texture.rotation`.
- Для Foundry VTT 14 эти удалённые поля, наоборот, исключаются из обновления.
- Свет, зрение, обнаружение, кольцо токена и прочие секции прототипа сбрасываются через полный валидный источник, а не через удаление полей DataModel.
- Откат при неудачной замене восстанавливает исходный полный `prototypeToken`.

Ошибка проявлялась только в режиме полной очистки и замены существующего персонажа. Создание нового Actor и обычное обновление не использовали опасное удаление полей прототипа токена.
