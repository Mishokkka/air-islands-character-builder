# Версия 1.0.11

## Исправлено

- Длинные тултипы талантов и заклинаний теперь можно прокручивать колесом мыши, не уводя курсор с названия записи.
- Курсор можно перевести с названия на сам тултип и пользоваться его полосой прокрутки. Задержка закрытия увеличена, чтобы карточка не исчезала при переходе через небольшой промежуток.
- Прокрутка самого тултипа больше не воспринимается как прокрутка страницы и не закрывает карточку.
- Добавлены `overscroll-behavior: contain`, стабильное место под полосу прокрутки и клавиатурный фокус для карточки описания.
- Добавлены автоматические проверки прокрутки колесом, сохранения тултипа при его внутренней прокрутке и перехода курсора на карточку.
