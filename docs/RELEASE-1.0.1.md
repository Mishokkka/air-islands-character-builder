# Release 1.0.1

## Лорные справочники

- Полностью обновлён список доступных верований по книгам «Введение в Острова» и «Боги и Люди».
- «Сон Зар-Лы» исключён из конструктора.
- Добавлены Замуд, Тримунэлия, Юниатство, Рамбар, Фаэлиранство, Дети Подшерстка, племенные орочьи и гоблинские верования и Критики.
- Сохранены отдельные варианты Янтарной и Андриатской Церквей.
- Краткие описания всех доступных стран переписаны по актуальному лору и теперь рассказывают о государстве, а не только о языке.

## Совместимость

- Форматы `.flchar` и `.flrules` не изменены.
- Кодовая база остаётся совместимой с Foundry VTT 13/14.
