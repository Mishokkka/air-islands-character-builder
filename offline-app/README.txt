КОНСТРУКТОР ПЕРСОНАЖА ВОЗДУШНЫХ ОСТРОВОВ, ВЕРСИЯ 2.0.0

Рекомендуемый вариант для игроков: страница GitHub Pages, которую выдаёт ГМ. Она автоматически получает новые правила и код, поэтому архивы перескачивать не требуется.

Локальный запуск:
1. Откройте index.html двойным щелчком.
2. Либо запустите ОТКРЫТЬ-КОНСТРУКТОР.bat из корня проекта.

При запуске через file:// автоматическая загрузка с GitHub может блокироваться браузером. В этом режиме используется встроенный резервный пакет. Локальная версия использует встроенный резервный пакет правил.

На веб-странице правила проверяются по SHA-256, сохраняются локально и используются при временном отсутствии интернета. Обновления правил проверяются автоматически. Служебные элементы управления правилами в интерфейсе игроков скрыты.

Редактор проверяет бюджеты характеристик, навыков, талантов, заклинаний, языков, Base XP и Reputation. Этап магии появляется для подходящего профессионального пути. При создании разрешён только один Professional Path. У мортаров вместо пути показываются системы и протоколы.

Таланты расположены в трёх компактных колонках на компьютере. Есть поиск и фильтры. Наведение на название показывает прокручиваемое полное описание, нажатие закрепляет его в отдельной панели. Покупки за Base XP отменяются прямо в строке навыка, таланта, Path или заклинания.

Кнопки отмены и повтора возвращают изменения текущего сеанса. Перед сменой основы персонажа редактор показывает зависимые покупки, которые придётся удалить. Черновик можно скачать через меню «Файл». На узких экранах выбор расового таланта и пути раскрывается по нажатию.

Экспорт .flchar создаёт один контейнер с анкетой, журналами покупок, использованным пакетом правил, портретом и токеном. Передайте готовый .flchar ГМу.

Формат персонажа: v8. Старые файлы открываются и мигрируют автоматически. Reputation оформляется строками «количество / причина / место» и переносится в Quick Access.
